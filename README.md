## 🚀 Despre Proiect
**TaskLocal** este o aplicație de tip marketplace local care conectează utilizatorii care au nevoie de ajutor rapid pentru sarcini zilnice (reparații minore, cumpărături, curățenie, mutări etc.) cu persoane din proximitate dorești să presteze serviciul în schimbul sumei stabilite.

---

## ✨ Funcționalități Principale (Features)
1. **Autentificare și Profil Utilizator:** Gestionarea contului pentru beneficiari și prestatori.
2. **Postare de Task-uri:** Utilizatorii pot crea sarcini noi specificând:
   - Titlu și descriere detaliată
   - Domeniul de activitate (ex: Casă și Grădină, Transport, IT, Ajutor general)
   - Bugetul / Suma oferită
   - Locația unde este nevoie de ajutor
3. **Listă Dinamică și Filtrare:** 
   - Vizualizarea task-urilor disponibile într-o listă derulantă.
   - Posibilitatea de filtrare a task-urilor în funcție de categorie sau zonă/proximitate.
4. **Hartă Interactivă:** Localizarea vizuală a task-urilor pe o hartă integrată.
5. **Sistem de Chat Integrat:** Odată ce un utilizator acceptă un task și suma aferentă, se deschide automat o cameră de chat privată între beneficiar și prestator.
6. **Validări de Securitate:** Prevenirea trimiterii formularelor incomplete (de exemplu, imposibilitatea de a posta un task fără titlu sau fără sumă validă).
